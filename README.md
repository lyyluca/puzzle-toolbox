# PuzzleToolbox

PuzzleToolbox is a collection of free, lightweight, and blazingly fast client-side puzzle solvers designed to help you solve grid puzzles, word searches, and ciphers without any server-side overhead or signup friction.

## Features

- **Block Blast Solver**: Optimize your grid placements and maximize your high scores.
- **Nonogram / Picross Solver**: Fast deterministic solver utilizing logical pre-passes and recursive backtracking.
- **Cryptogram & Caesar Cipher Decoder**: Frequency analysis-driven tools to decrypt substitution ciphers instantly.
- **Word Search Solver**: Find hidden words in any grid layout using an optimized prefix tree (Trie).

## Tech Stack

- **Frontend**: Tailwind CSS for responsive styling.
- **Logic**: Vanilla ES6 JavaScript (Client-side execution).
- **Deployment**: Static hosting on Vercel.

## How to Use

Simply clone the repository and open `index.html` in your browser. No build steps or installations required!
